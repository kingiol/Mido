# Mido iOS Demo

SwiftUI demo app for the `MidoClient` Swift Package.

Open `MidoDemo.xcodeproj` in Xcode, select the `MidoDemo` scheme, and run it on an iOS simulator.

The app starts in mock mode so it can demonstrate local client tools without a server. Switch to local server mode to connect to the web demo API at `http://127.0.0.1:3030`.
